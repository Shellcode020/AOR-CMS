# AOR-CMS
A CMS for AO-Rebirth Local Servers
## Read SETUP-INSTRUCTIONS to set up these files without errors!
Important Note: For the server status to work, the webfiles must run from same machine as the server. The server status checks when the AccountBroker process has started to display the online/offline and uptime status.
- Download AOR-CMS v1.0 from the release page - https://github.com/Shellcode020/AOR-CMS/releases/tag/Release

Features:
- Homepage
  > - Server Status
  > - Players Online
  > - Latency
  > - Registered Accounts
  > - Characters
  > - Integrated Discord-News
  
- Nano Programs (Database)
  > - Shows all nanos for each profession with skill requirements.
  > - Hover over the nano to see effects.
  
- Items (Database)
  > - Item Lookup, find your items in the search bar.
  > - Click on the item to see detailed description.
  
- Guides
  > - All (community) guides directly from your CMS.
  
- Download
  > - Shows the downloadable client.
  
- Support
  > - Shows the Support / FAQ page.
  
- Account Panel
  > - Login and Register
  > - Menu: Account Name, Account Type (Player / GM), Account Status (Active/Banned)
  > - Character List: Shows Character Name, Location, Unstuck.
  > - Account Details: Shows Username, First Name, Last Name, Email with options to edit them except for username.
  > - Change Password: Allows you to change your password.
